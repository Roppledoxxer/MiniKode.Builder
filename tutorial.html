01 / ABOUT

What is MiniKode?

Get to know the language and the tool before writing your first program.

</>

A smaller way to build

MiniKode is a small, custom language interpreted by MiniKode.Builder in your browser. You write short commands to create page elements, style them, change their content, and add interactions.

MiniKode is not HTML, CSS, or JavaScript. The Builder reads MiniKode code and uses browser features to create the result in the Preview panel.

▣

What the Builder does

The Builder gives you an editor, a live preview, a console for messages and errors, quick templates, and tools to format, save, load, and run your program.

⌘

What you can make

Build simple interfaces, counters, task lists, cards, interactive controls, and basic physics demonstrations. The language is designed for small browser projects and learning.

i

Important: MiniKode does not run arbitrary JavaScript. Its commands and expression rules are limited to the features described on this page. Use HTML/CSS-style values inside the supported parameters when you need to control how an element looks.

02 / THE STARTING POINT

Basics to MiniKode's Builder

Learn the shape of a program, create elements, and give them content and style.

LESSON 01

Every program needs a beginning and an ending

A MiniKode program starts with BMK and ends with EMK. Put your MiniKode commands between these two lines. Write each marker on its own line.

  • BMK means the program begins.
  • EMK means the program ends.
  • Blank lines are allowed between commands.
  • Lines beginning with // are comments and are ignored.
YOUR FIRST PROGRAM
BMK
// My first MiniKode program
let message = "Hello, MiniKode!"
log message
EMK
LESSON 02

Create an element

The create command makes an HTML element and places it inside a target. You can give the element an ID, one or more classes, a size, and parameters.

create tag#id.class -> target [widthxheight] { ... }

The target can be preview, root, body, a CSS selector such as #app, or an element that MiniKode has already created. The target is optional; if it is left out, the element goes into preview.

CREATE A BOX AND A TITLE
BMK
create div#app.panel -> preview [100%x100%] {
  style: "padding: 24px; background: #101828"
}
create h1#heading -> #app {
  text: "Welcome!"
  style: "color: #63e6be; font-size: 32px"
}
EMK

How to read the create line

create

The command that creates an element.

div

The HTML tag to create.

#app

An optional ID. Use it later to find the element.

.panel

An optional CSS class. More classes can be added with more dots.

-> preview

The parent element that receives the new element. @ also works as an older target separator.

[100%x100%]

Optional width and height. Plain numbers become pixels; units such as % are kept.

{ ... }

The parameter block: content, style, attributes, and other settings.

LESSON 03

Give elements content and style

Inside the braces, write a parameter name, a colon, and its value. You can put multiple parameters on separate lines or separate them with semicolons or commas. Put text values in quotes.

The style parameter uses regular CSS declarations. Separate each CSS rule with a semicolon.

PARAMETER EXAMPLE
BMK
create button#save.primary -> preview {
  text: "Save project"
  attr: "type=button;title=Save your work"
  style: "padding: 12px 18px; background: #123b33; color: white; border: 0; border-radius: 8px"
}
EMK

MINIKODE SYNTAX RULES

Small rules that prevent big errors

One top-level command per line

Write separate program commands on separate lines. Semicolons are used to separate multiple statements inside event, condition, and repeat actions.

Use quotes for text

Write text in single or double quotes. Numbers and values such as true, false, null, and undefined can be written without quotes.

Keep IDs consistent

Create div#panel, then refer to it as #panel. The element must exist before a command tries to use it.

Close every create block

Every opening { in a create command needs a matching }. Create blocks can span multiple lines.

Separate CSS rules

Inside a quoted style value, use property: value; property: value. CSS property names can use kebab-case.

Separate parameters clearly

Parameter entries can be placed on new lines or separated with commas or semicolons. Keep values containing punctuation inside quotes.

Comments are ignored

A line beginning with // is a comment. You can use comments to explain what a section of code does.

Continue a long line

A backslash \ at the end of a line joins the next line to it. Usually, multiline create blocks are easier to read.

LESSON 04

Use variables and show their values

A variable stores a value so you can use it again. Create one with let. Put its name inside double curly braces to insert its value into text or another quoted value.

You can also read a common element property directly, such as #task.value, or use it in interpolation as {{#task.value}}.

VARIABLES AND VALUES
BMK
let player = "Roppledoxxer"
let score = 25
create h2#label -> preview {
  text: "Player: {{player}}"
}
create p#points -> preview {
  text: "Score: {{score}}"
}
EMK
!

Remember: A variable is not automatically a live display. When its value changes, use a set command to update the element that shows it, as in the Counter example below.

VARIABLESlet

Store information

Make a variable with a name and a value. The value may be a quoted string, number, boolean, null, or another variable's value.

let name = "Alex"
let score = 0
let isReady = true

Variable names can use letters, numbers, _, and $, but must not start with a number.

ELEMENTScreate

Build a page element

Use a tag name, optional ID and classes, optional target, optional size, and a parameter block.

create div#card.box -> preview [320x180] {
  text: "My card"
}

Target separator -> is recommended. @ is also accepted. Without a target, MiniKode uses preview.

UPDATEset

Change an element

Update text, HTML, value, style, attributes, or classes after the element exists.

set #title text "New title"
set #input value "Hello"
set #card style "padding: 20px"

Use set #thing prop propertyName=value for an allowed element property. Properties such as innerHTML and outerHTML are blocked through prop.

VISIBILITYshow / hide

Control visibility

Show an element, hide it, switch its hidden state, or remove it from the page.

hide #help
show #help
toggle #menu
remove #old-card
CLASSESaddclass

Change CSS classes

Add or remove one or more classes without replacing the element's other classes.

addclass #card selected
delclass #card selected
INTERACTIONon

Listen for an event

Attach MiniKode statements to an element event. The action runs when that event occurs.

on #button click => log "Clicked!"
on #name input => log #name.value

Common event names include click, input, change, and keydown. The runtime can bind other browser event names too.

MATHincrement

Change a number

Add or subtract 1 by default, or give a different amount.

increment score
increment score 5
decrement lives
decrement lives 2
LOOPSrepeat

Repeat a command

Run a command a chosen number of times. Inside the repeated command, $index starts at 0 and increases by 1.

repeat 4 => create div.tile -> #grid {
  text: "Tile {{ $index }}"
}

The repeat count is a whole number. The runtime limits one repeat command to 1,000 iterations.

CONDITIONSif

Run code only when true

The command after => runs only when the expression before it is true.

if score >= 10 => log "Level up!"
if lives == 0 => show #game-over
UTILITYlog / alert

Send messages and actions

Use these commands to print a message, show a popup, delay an action, send a custom event, or focus an element.

log "Saved!"
alert "Are you sure?"
wait 500 => log "Half a second later"
emit game-start "level-1"
focus #name
VALUES{{ }}

Insert a value into text

Use double curly braces to insert a variable, a dotted variable path, or a supported element property.

text: "Score: {{score}}"
text: "Typed: {{#name.value}}"
let points = 12
log "Points: {{points}}"

Supported readable element properties include value, text, checked, disabled, hidden, title, id, and class.

EXPRESSIONSexpr(...)

Use MiniKode math and logic

Expressions are supported by if and by values written as expr(...). MiniKode supports these operators:

+ - Add / subtract * / % Multiply / divide / remainder < > <= >= Compare == != === !== Check equality && || ! AND / OR / NOT ( ) Group expressions 
let total = expr(5 * (2 + 3))
if total == 25 => log "Correct"

This is a limited expression language, not full JavaScript. Function calls, loops written as JavaScript, and arbitrary JavaScript code are not supported.

DATAjson(...)

Read JSON values

Use json(...) when you need to parse a JSON value into a variable.

let settings = json({"theme":"dark","volume":5})

The contents must be valid JSON. JSON keys and text values need double quotes.

PHYSICSphysics

Give an element motion

Turn on simple motion for an element. Set a starting position in CSS and provide a velocity as horizontal and vertical numbers.

create div#ball -> #world [40x40] {
  style: "position: absolute; left: 40px; top: 30px; background: #4dabf7; border-radius: 50%"
  physics: true
  velocity: "3,-1"
  bounce: .8
  friction: .995
  gravity: .45
}

velocity is written as "x,y". You can also set vx and vy. static: true skips movement. Physics objects bounce within their parent container.

BUILDER TOOLSSave / Load

Use the Builder tools

The toolbar actions belong to MiniKode.Builder itself, not the MiniKode language.

  • Run / RefreshBuild the program in Preview.
  • FormatRearrange the program into a consistent layout.
  • Save / LoadStore or restore the project in this browser.
  • ClearEmpty the editor and clear the current preview.
  • Ctrl + EnterRun the current program.
  • TabInsert two spaces in the editor.

Save and Load use this browser's local storage. They do not automatically upload your project to a website or another device.

PUT IT TOGETHER

A complete working counter

This example creates a display and three buttons. Each button listens for a click, changes the count variable, and updates the display with set.

Paste it into the Builder Editor and press Run.

COUNTER.MKD
BMK
let count = 0

create div#app -> preview [100%x100%] {
  style: "display: flex; align-items: center; justify-content: center; background: #101828; font-family: system-ui"
}
create div#card -> #app {
  style: "background: white; color: #222; padding: 32px; border-radius: 18px; text-align: center; min-width: 280px"
}
create h1#heading -> #card {
  text: "MiniKode Counter"
}
create h2#display -> #card {
  text: "{{count}}"
  style: "font-size: 64px; margin: 16px"
}
create div#buttons -> #card {
  style: "display: flex; gap: 8px; justify-content: center"
}
create button#minus -> #buttons { text: "-" }
create button#reset -> #buttons { text: "Reset" }
create button#plus -> #buttons { text: "+" }

on #minus click => decrement count; set #display text "{{count}}"
on #reset click => let count = 0; set #display text "{{count}}"
on #plus click => increment count; set #display text "{{count}}"
EMK
WHEN SOMETHING GOES WRONG

Quick troubleshooting

Most beginner errors come from a missing marker, a misspelled ID, or a value that is not written in the right format.

“Program must start with BMK”

Put BMK by itself on the first non-empty line. Do not put another command on the same line.

“Program must end with EMK”

Put EMK by itself on the last non-empty line.

“Target was not found” or “Element was not found”

Check that the parent or ID exists before trying to place an element inside it or change it. IDs are written with #, for example #app.

“Unknown command”

Check spelling and make sure you are using a MiniKode command supported by the runtime. MiniKode commands are not JavaScript statements.

My variable changed, but the screen did not

Update the element that displays it. For example: increment count; set #display text "{{count}}".

My style is not applying

Write CSS inside a quoted style value, use a colon between each CSS property and value, and separate CSS rules with semicolons.

My click event does nothing

Make sure the target element was created before the on line, the ID matches exactly, and the action after => is valid MiniKode.

My physics object does not move as expected

Give it a size, a starting left and top style, and a two-number velocity. Make sure its parent has a visible size and acts as the object's container.
